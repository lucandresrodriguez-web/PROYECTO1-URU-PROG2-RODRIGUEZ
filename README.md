Descripcion general del programa: "El programa en cuestion tiene el objetivo de servir como administrador de un taller donde se puedan gestionar distintos tipos de vehiculos, repuestos, ordenes de servicio y mecanicos en cuestion. Todo a partir del uso de los elementos vistos hasta el momento como punteros, memoria dinamica, estructuras generales en el lenguaje de C++ y la compilacion a partir de GitBash; aprovechando tambien la separacion entre las capas tanto de la logica y la presentacion".
